# AGENTS.md

This repository holds DUNE's software policies as a Zensical site.

- Each policy is one page in `docs/`. The status, version and owner on a page
  must match the snapshot table in `docs/index.md`.
- Where a policy has an authoritative write-up elsewhere (for example in
  DocDB), the page summarises it and links to it. Do not change what a policy
  requires without a matching change to that write-up.
- Do not mark a policy Adopted unless CRAB has ratified it.
- Run `make build` and `make check-public` before opening a pull request.
